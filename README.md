# IBM SpaceX Data Science Capstone

An in-progress IBM Data Science Capstone project investigating factors that influence the successful landing of SpaceX Falcon 9 first-stage boosters.

## Project scope

- SpaceX API and launch-record data collection
- Data cleaning and exploratory analysis with Python and SQL
- Launch-site mapping using Folium
- Interactive analysis with Plotly Dash
- Landing prediction using classification models

## Status

**Work in progress.** Completed, executed notebooks, original charts, dashboard code, results, and a final presentation will be added after verification. Lab templates and example screenshots are not presented as completed analysis.
